# 设置页待实现接口

设置页当前是纯前端界面：学校邮箱、教学信息服务网的状态与版本号读取的是已有
`window.dela` API（不跳转新接口）。下表列出剩余交互后续要接入的接口；接入之前，
界面上的选择只在组件内生效，不会持久化，也不实际改变应用行为。

| 界面位置                               | 交互                 | 待实现接口（草案）                                                           | 说明                                                                            |
| -------------------------------------- | -------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 外观 › 主题                            | 记住所选主题         | `dela.settings`: `getPreference(key)` / `setPreference(key, value)`          | 偏好可先只存 localStorage；需要与原生窗口（标题栏、系统主题注册）联动时再走 IPC |
| 外观 › 主题                            | 让所选主题真正生效   | renderer 改动：明暗 token 迁移到 `.dark` class 并声明 `@custom-variant dark` | `globals.css` 目前按 `prefers-color-scheme` 定义暗色，改类切换需同步该文件      |
| 数据与服务 › Canvas                    | 连接状态、登录与断开 | `dela.canvas`: `getState()` / `connect()` / `disconnect()`                   | 登录参照课表的独立持久 Session 窗口模式                                         |
| 数据与服务 › 致远一号                  | 模型访问配置         | `dela.agent`: `getState()` / `configure()`                                   | API Key 经 `safeStorage` 保存，不进入 renderer                                  |
| 数据与服务 › 工作目录                  | 选择并记住目录       | `dela.workspace`: `choose()` / `get()`                                       | 系统目录选择对话框；路径属于业务状态，持久化位置随实现确定                      |
| 数据与服务 › 学校邮箱 / 教学信息服务网 | 已可用，无新接口     | 复用 `dela.mail` / `dela.timetable`                                          | 「配置」跳转对应页面；如需在设置页断开，两者已有 `disconnect()`                 |
