# 设置页接口

设置页只暴露具体、已实现的操作；renderer 不读取已存凭据或数据库。

| 界面位置                               | 操作                 | 受控 API                                                                                              | 实际行为                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------- | -------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 外观 › 主题                            | 读取/保存主题        | `dela.settings.getTheme()` / `setTheme(theme)`                                                        | `theme` 只接受 `system`、`light`、`dark`，保存到本地 SQLite；主进程同步 Electron `nativeTheme`，renderer 用 `html.light` / `html.dark` 切换 token。                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 外观 › 应用图标                        | 读取/保存图标底色    | `dela.settings.getIcon()` / `setIcon(icon)`                                                           | `icon` 只接受 `white`（默认）、`black`，保存到本地 SQLite；主进程在下次启动创建窗口时加载对应 `assets/Dela_<色>_bg.png`，运行中不热切换。                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 外观 › 页面缩放                        | 读取/保存缩放        | `dela.settings.getZoom()` / `setZoom(zoom)`                                                           | `zoom` 只接受 0.9、1、1.1、1.25、1.5 五档，保存到本地 SQLite；主进程对窗口立即 `setZoomFactor` 并在下次启动恢复。快捷键 Ctrl/⌘ `=`/`-`/`0` 在档位间步进。                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 外观 › 字号                            | 读取/保存字号        | `dela.settings.getFontScale()` / `setFontScale(scale)`                                                | `scale` 只接受 0.9、1、1.1、1.25 四档，保存到本地 SQLite；renderer 通过根节点 `--font-scale` 变量缩放 rem 字号（`text-xs` 等），不缩放 px 任意值、间距与图标。                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 数据与服务 › Canvas                    | 配置、替换令牌、断开 | `dela.canvas.configure()` / `syncCourses()` / `disconnect()`                                          | 令牌先经 Canvas profile 请求验证，再由主进程用 `safeStorage` 加密保存；连接后同步课程列表，断开会删除令牌但保留已缓存资料。                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 模型服务                               | 管理多个 LLM 提供商  | `dela.llm.list()` / `save()` / `remove()` / `setActive()` / `setModel()` / `setEffort()` / `verify()` | 提供商配置（名称、API 地址、模型列表、API Key）整体经 `safeStorage` 加密保存在主进程，`list()` 只返回不含密钥的视图；预设（致远一号/DeepSeek/MiniMax/智谱 Coding Plan/自定义）只预填默认值。`verify()` 用 GET 模型列表端点检测密钥（401/403 视为无效），成功时可导入返回的模型列表；新建提供商自动启用，`setModel()` 只在当前提供商的模型列表内切换；旧版致远一号单凭据首次访问时自动迁移为一条提供商配置。推理强度为可选的多选档位（none/minimal/low/medium/high/xhigh/max/ultra 子集），开启后 `setEffort()` 在已勾选档位内切换并随请求下发 `reasoning_effort`，关闭时对话输入框显示 default 且不可改。 |
| 数据与服务 › 工作目录                  | 选择位置             | `dela.workspace.chooseDirectory()` / `getState()`                                                     | 调用系统目录选择器并保存目录；只影响之后新建的顶层内容和课程文件，不迁移已有文件。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 数据与服务 › 学校邮箱 / 教学信息服务网 | 打开相应配置页       | `dela.mail` / `dela.timetable`                                                                        | 这两项已有独立、完整的连接与断开流程，因此设置页明确显示为「前往」而不复制表单。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 数据与服务 › 学校邮箱 › 已删除保留     | 选择回收站保留期     | `dela.mail.getTrashRetention()` / `setTrashRetention(r)`                                              | 仅邮箱已连接且保留期读取成功后显示；`r` 只接受 7/30/90 天或永久（0），默认 30 天，主进程保存并按期自动清理本地已删除邮件。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
