# 设置页接口

设置页只暴露具体、已实现的操作；renderer 不读取已存凭据或数据库。设置通道统一由主进程 `src/main/settings/ipc.ts` 注册（自 main/index.ts 内联迁出，行为不变），偏好落在本地 SQLite `workspace_settings` 表。

| 界面位置                         | 操作                 | 受控 API                                                                                              | 实际行为                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------- | -------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 外观 › 主题                      | 读取/保存主题        | `dela.settings.getTheme()` / `setTheme(theme)`                                                        | `theme` 只接受 `system`、`light`、`dark`，保存到本地 SQLite；主进程同步 Electron `nativeTheme`，renderer 用 `html.light` / `html.dark` 切换 token。                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 外观 › 应用图标                  | 读取/保存图标底色    | `dela.settings.getIcon()` / `setIcon(icon)`                                                           | `icon` 只接受 `white`（默认）、`black`，保存到本地 SQLite；主进程在下次启动创建窗口时加载对应 `assets/Dela_<色>_bg.png`，运行中不热切换。                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 外观 › 页面缩放                  | 读取/保存缩放        | `dela.settings.getZoom()` / `setZoom(zoom)`                                                           | `zoom` 只接受 0.9、1、1.1、1.25、1.5 五档，保存到本地 SQLite；主进程对窗口立即 `setZoomFactor` 并在下次启动恢复。快捷键 Ctrl/⌘ `=`/`-`/`0` 在档位间步进。                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 外观 › 字号                      | 读取/保存字号        | `dela.settings.getFontScale()` / `setFontScale(scale)`                                                | `scale` 只接受 0.9、1、1.1、1.25 四档，保存到本地 SQLite；renderer 通过根节点 `--font-scale` 变量缩放 rem 字号（`text-xs` 等），不缩放 px 任意值、间距与图标。                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 通用 › 开机自启动                | 读取/保存自启        | `dela.settings.getOpenAtLogin()` / `setOpenAtLogin(enabled)`                                          | 打包版以系统启动项为准（含任务管理器改动），开发运行读本地偏好；持久化为 `open-at-login` 行（'1'/'0'，缺省视为开启）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 通知 › 校园消息系统提醒          | 读取/保存开关        | `dela.settings.getCampusNotifications()` / `setCampusNotifications(enabled)`                          | 持久化为 `campus-notifications` 行（'0' 关闭，缺省开启）。只影响 `systemNotifyItem` 的桌面弹窗（新邮件/水源互动）；通知收集与应用内通知中心不受影响。                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 通知 › Agent 任务通知            | 读取/保存偏好        | `dela.settings.getTaskNotifications()` / `setTaskNotifications(prefs)`                                | `prefs` 为 `{ completed, failed }`，持久化为 `task-notifications` 行（JSON，缺省 completed=false、failed=true）。Run 终态由 `src/main/settings/task-notify.ts` 在 `finishRun` 后按偏好经 `systemNotifyToast` 弹系统提醒（复用基线/暂停/聚焦守卫）；`stopped` 不提醒，关闭提醒不影响会话记录与侧栏状态。                                                                                                                                                                                                                                                                                                   |
| 通知 › 暂停通知                  | 暂停/恢复            | `dela.notifications.setSnooze(until)`（读 `getState().snoozedUntil`）                                 | 与通知中心**同一份**状态（`notifications-snoozed-until` 行），不造第二开关；设置页订阅 `notifications:state` 广播与通知中心实时同步。                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 工作区 › 工作目录                | 选择位置             | `dela.workspace.chooseDirectory()` / `getState()`                                                     | 调用系统目录选择器并保存目录；只影响之后新建的顶层内容和课程文件，不迁移已有文件。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 工作区 › 启动恢复                | 读取/保存偏好        | `dela.settings.getWorkspacePrefs()` / `setWorkspacePrefs(patch)`                                      | `patch` 支持 `{ restoreLastProject }`，持久化为 `workspace-prefs` 行（JSON，缺省 restoreLastProject=true 与现行为一致）。启动消费由 app/ 装配层调用 `getWorkspacePrefs()` 读取后导航（本批交付 API，接线见协调说明）。                                                                                                                                                                                                                                                                                                                                                                                    |
| 工作区 › 默认笔记编辑方式        | 读取/保存偏好        | `dela.settings.setWorkspacePrefs({ defaultNoteEditMode })`                                            | `defaultNoteEditMode` 只接受 `rich`（所见即所得，默认）/`source`；持久化进 `workspace-prefs` 行。NoteTab 打开笔记时的初始模式消费由 content/note 接线（本批交付 API 与设置页）。                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 工作区 › 布局重置                | 重置当前项目布局     | `dela.layout.save(projectId, defaultLayout)`                                                          | 把当前项目的 `layout:{projectId}` 布局写回默认单组空标签；下次进入该项目（或重启）时生效。当前项目 id 读取与 App 导航一致的 `localStorage['dela.workspace.project']`（空串 = 通用布局 `_general`）。                                                                                                                                                                                                                                                                                                                                                                                                      |
| 模型服务                         | 管理多个 LLM 提供商  | `dela.llm.list()` / `save()` / `remove()` / `setActive()` / `setModel()` / `setEffort()` / `verify()` | 提供商配置（名称、API 地址、模型列表、API Key）整体经 `safeStorage` 加密保存在主进程，`list()` 只返回不含密钥的视图；预设（致远一号/DeepSeek/MiniMax/智谱 Coding Plan/自定义）只预填默认值。`verify()` 用 GET 模型列表端点检测密钥（401/403 视为无效），成功时可导入返回的模型列表；新建提供商自动启用，`setModel()` 只在当前提供商的模型列表内切换；旧版致远一号单凭据首次访问时自动迁移为一条提供商配置。推理强度为可选的多选档位（none/minimal/low/medium/high/xhigh/max/ultra 子集），开启后 `setEffort()` 在已勾选档位内切换并随请求下发 `reasoning_effort`，关闭时对话输入框显示 default 且不可改。 |
| 连接 › Canvas                    | 配置、替换令牌、断开 | `dela.canvas.configure()` / `syncCourses()` / `disconnect()`                                          | 令牌先经 Canvas profile 请求验证，再由主进程用 `safeStorage` 加密保存；连接后同步课程列表，断开会删除令牌但保留已缓存资料。表单与连接逻辑收编在 `features/settings/connections/`。                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 连接 › 学校邮箱 / 教学信息服务网 | 打开相应配置页       | `dela.mail` / `dela.timetable`                                                                        | 这两项已有独立、完整的连接与断开流程，因此设置页明确显示为「前往」而不复制表单。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 连接 › 学校邮箱 › 已删除保留     | 选择回收站保留期     | `dela.mail.getTrashRetention()` / `setTrashRetention(r)`                                              | 仅邮箱已连接且保留期读取成功后显示；`r` 只接受 7/30/90 天或永久（0），默认 30 天，主进程保存并按期自动清理本地已删除邮件。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 插件 › 自定义指令                | 指令 CRUD            | `dela.chat.listCommands()` / `saveCommand()` / `deleteCommand()`                                      | 自定义 / 指令（prompt）在 composer 输入 / 时触发；Skills 与 MCP 页签为阶段四交付的说明位，不提供任何开关。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

设置内搜索（`SettingsSearch`）与全局搜索的设置入口共用 `features/settings/search-index.ts` 单一关键词表：按分类、选项标题与内置关键词（如「主题→外观」「API→模型服务」「邮件→连接」）过滤，选中后跳转对应分类并高亮目标卡片（`data-setting-id` + 1.8s ring）。
