# 设置页接口

设置页只暴露具体、已实现的操作；renderer 不读取已存凭据或数据库。设置通道统一由主进程 `src/main/settings/ipc.ts` 注册，偏好落在本地 SQLite `workspace_settings` 表。

分区与侧栏分组（`shared/settings.ts` 的 `SettingsSectionId` 是唯一契约，`SettingsNav.tsx` 的 `sections` 目录按 `group` 聚拢）：

| 分组 | 分区（id）                                                                                      |
| ---- | ----------------------------------------------------------------------------------------------- |
| 基本 | 通用 general、外观 appearance、快捷键 shortcuts                                                 |
| 数据 | 工作区 workspace、已归档 archived、连接 connections                                             |
| 模型 | 模型供应商 providers、内置能力 capabilities、自定义指令 commands、Skills skills、MCP Server mcp |
| 关于 | 关于 about、隐私条款 privacy                                                                    |

2026-10-06 用户裁决：取消「插件」分组标题，其四个分区并入「模型」；已归档对话从「工作区」拆出为独立分区 `archived`。

| 界面位置                                    | 操作                   | 受控 API                                                                                                                  | 实际行为                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 通用 › 开机自启动                           | 读取/保存自启          | `dela.settings.getOpenAtLogin()` / `setOpenAtLogin(enabled)`                                                              | 打包版以系统启动项为准（含任务管理器改动），开发运行读本地偏好；持久化为 `open-at-login` 行（'1'/'0'，缺省视为开启）。                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 通用 › 系统通知 › 校园消息提醒              | 读取/保存开关          | `dela.settings.getCampusNotifications()` / `setCampusNotifications(enabled)`                                              | 持久化为 `campus-notifications` 行（'0' 关闭，缺省开启）。只影响 `systemNotifyItem` 的桌面弹窗（新邮件/水源互动）；通知收集与应用内通知中心不受影响。                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 通用 › 系统通知 › Agent 任务通知            | 读取/保存偏好          | `dela.settings.getTaskNotifications()` / `setTaskNotifications(prefs)`                                                    | `prefs` 为 `{ completed, failed }`，持久化为 `task-notifications` 行（JSON，缺省 completed=false、failed=true）。Run 终态由 `src/main/settings/task-notify.ts` 在 `finishRun` 后按偏好经 `systemNotifyToast` 弹系统提醒（复用基线/暂停/聚焦守卫）；`stopped` 不提醒，关闭提醒不影响会话记录与侧栏状态。                                                                                                                                                                                                                                                               |
| 通用 › 系统通知 › 暂停通知                  | 暂停/恢复              | `dela.notifications.setSnooze(until)`（读 `getState().snoozedUntil`）                                                     | 与通知中心**同一份**状态（`notifications-snoozed-until` 行），不造第二开关；设置页订阅 `notifications:state` 广播与通知中心实时同步。                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 外观 › 主题                                 | 读取/保存主题          | `dela.settings.getTheme()` / `setTheme(theme)`                                                                            | `theme` 只接受 `system`、`light`、`dark`，保存到本地 SQLite；主进程同步 Electron `nativeTheme`，renderer 用 `html.light` / `html.dark` 切换 token。                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 外观 › 页面缩放                             | 读取/保存缩放          | `dela.settings.getZoom()` / `setZoom(zoom)`                                                                               | `zoom` 只接受 0.9、1、1.1、1.25、1.5 五档，保存到本地 SQLite；主进程对窗口立即 `setZoomFactor` 并在下次启动恢复。快捷键在档位间步进（默认 Ctrl/⌘ `=`/`-`/`0`，可改键）。                                                                                                                                                                                                                                                                                                                                                                                              |
| 外观 › 字号                                 | 读取/保存字号          | `dela.settings.getFontScale()` / `setFontScale(scale)`                                                                    | `scale` 只接受 0.9、1、1.1、1.25 四档，保存到本地 SQLite；renderer 通过根节点 `--font-scale` 变量缩放 rem 字号（`text-xs` 等），不缩放 px 任意值、间距与图标。                                                                                                                                                                                                                                                                                                                                                                                                        |
| 外观 › 应用图标                             | 读取/保存图标底色      | `dela.settings.getIcon()` / `setIcon(icon)`                                                                               | `icon` 只接受 `white`（默认）、`black`，保存到本地 SQLite；主进程在下次启动创建窗口时加载对应 `assets/Dela_<色>_bg.png`，运行中不热切换。                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 快捷键                                      | 读取/保存/重置键位     | `dela.settings.getKeybindings()` / `setKeybindings(patch)` / `resetKeybindings()`                                         | 覆盖项持久化为 `keybindings` 行（JSON，**只存与默认不同的动作**，null 表示显式解绑；缺键或损坏回退全默认）。动作目录与默认键位在 `shared/keybindings.ts`（16 个动作：文件/导航/视图 11 个全局 + 工作台 5 个）；`app/shortcuts.ts` 持有 renderer 镜像，AppShell 派发全局动作、Workbench 经 props 取表派发工作台动作。录制时拒绝与同表内其他动作冲突的组合；`focus-group` 为 digit 族（末位接受 1…9）。编辑器内部键位（复制/保存等）与鼠标手势不在此表内。                                                                                                              |
| 工作区 › 工作目录                           | 选择位置               | `dela.workspace.chooseDirectory()` / `getState()`                                                                         | 调用系统目录选择器并保存目录；只影响之后新建的顶层内容和课程文件，不迁移已有文件。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 工作区 › 启动页面                           | 读取/保存偏好          | `dela.settings.getWorkspacePrefs()` / `setWorkspacePrefs(patch)`                                                          | 启动固定进入首页聊天，选择项目后恢复其标签布局；该页只显示说明，不再提供启动恢复开关。旧 `restoreLastProject` 字段保留兼容，但 app/ 不再消费。默认笔记编辑方式继续通过此偏好 API 保存。                                                                                                                                                                                                                                                                                                                                                                               |
| 工作区 › 默认笔记编辑方式                   | 读取/保存偏好          | `dela.settings.setWorkspacePrefs({ defaultNoteEditMode })`                                                                | `defaultNoteEditMode` 只接受 `rich`（所见即所得，默认）/`source`；持久化进 `workspace-prefs` 行。NoteTab 打开笔记时的初始模式消费由 content/note 接线。                                                                                                                                                                                                                                                                                                                                                                                                               |
| 工作区 › 布局重置                           | 重置当前项目布局       | `dela.layout.save(projectId, defaultLayout)`                                                                              | 把当前项目的 `layout:{projectId}` 布局写回默认单组空标签；下次进入该项目（或重启）时生效。当前项目 id 读取与 App 导航一致的 `localStorage['dela.workspace.project']`（空串 = 通用布局 `_general`）。                                                                                                                                                                                                                                                                                                                                                                  |
| 工作区 › 已隐藏项目                         | 恢复导航入口           | `useProjectNavPrefs`（localStorage 导航偏好）                                                                             | 隐藏只收起侧栏入口，项目文件与会话都不受影响；卡片仅在存在隐藏项目时出现。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 已归档                                      | 搜索/筛选/恢复/删除    | `dela.session.archived()` / `session.remove(id)` / `session.update(id, { archived: false })`                              | 独立分区：顶部搜索框（按标题）、项目筛选下拉（全部项目 + 已归档数据中出现过的项目）、`全部删除`（两步确认，逐条 `session:remove`）；列表按项目分组，组头为项目名 + 条数，行内显示标题与更新时间，操作为查看 / 恢复 / 永久删除（永久删除两步确认）。永久删除要求先归档（`session:remove` 拒绝未归档会话），不可撤销。                                                                                                                                                                                                                                                  |
| 连接 › Canvas                               | 配置、替换令牌、断开   | `dela.canvas.configure()` / `syncCourses()` / `disconnect()`                                                              | 令牌先经 Canvas profile 请求验证，再由主进程用 `safeStorage` 加密保存；连接后同步课程列表，断开会删除令牌但保留已缓存资料。表单与连接逻辑收编在 `features/settings/connections/`。                                                                                                                                                                                                                                                                                                                                                                                    |
| 连接 › 学校邮箱 / 教学信息服务网 / 水源社区 | 打开相应配置页         | `dela.mail` / `dela.timetable` / `dela.shuiyuan`                                                                          | 这三项已有独立、完整的连接与断开流程，因此设置页明确显示为「前往」而不复制表单；水源在已绑定时提供两步确认的解绑。                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 连接 › 学校邮箱 › 已删除保留                | 选择回收站保留期       | `dela.mail.getTrashRetention()` / `setTrashRetention(r)`                                                                  | 仅邮箱已连接且保留期读取成功后显示；`r` 只接受 7/30/90 天或永久（0），默认 30 天，主进程保存并按期自动清理本地已删除邮件。                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 模型供应商                                  | 管理多个 LLM 提供商    | `dela.llm.list()` / `save()` / `remove()` / `setActive()` / `verify()`                                                    | 左侧提供商列表（按预设/自定义分组）+ 右侧详情的两栏布局。提供商配置（名称、API 地址、模型列表、API Key）整体经 `safeStorage` 加密保存在主进程，`list()` 只返回不含密钥的视图；预设（致远一号/DeepSeek/MiniMax/智谱 Coding Plan/自定义）只预填默认值。`verify()` 用 GET 模型列表端点检测密钥（401/403 视为无效），成功时可导入返回的模型列表；新建提供商自动启用；推理强度为可选的多选档位（none/minimal/low/medium/high/xhigh/max/ultra 子集），开启后随请求下发 `reasoning_effort`。每轮请求的模型与档位切换由对话输入框负责（`setModel`/`setEffort`），不在设置页。 |
| 内置能力                                    | 查看/开关 Agent 工具   | `dela.capability.listBuiltinCapabilities()` / `setBuiltinCapability(name, enabled)` / `setBuiltinDomain(domain, enabled)` | 列出 38 个内置 Agent 工具（按 8 个能力域分组，含描述与领域标签）。停用清单持久化为 `tools-disabled` 行（JSON 数组，**只存停用项**，缺键/损坏即全开）；停用后该工具从模型工具表移除，并在执行侧返回 `DISABLED` 错误（旧工具名别名同样受门禁）。`read_resource`、`read_skill`、`read_skill_file` 为常驻能力（被其他工具描述依赖），只读展示原因、不可关闭。只影响 Agent 工具，不影响应用自身的同步与界面。                                                                                                                                                              |
| 自定义指令 › Instruction                    | 读取/保存全局附加指令  | `dela.settings.getInstruction()` / `setInstruction(text)`                                                                 | 持久化为 `agent-instruction` 行（纯文本，缺省空串 = 不注入，上限 2000 字符，写入前 trim）。每次 Run 由 `session/manager.ts` 读取并交给 `context/assemble.ts`，注入位置在**基础系统设定之后、Skill 索引与历史摘要之前**（优先级仅次于系统设定，边界仍以基础设定为准）；空串不追加该段。文案上限与下方快捷指令一致。                                                                                                                                                                                                                                                    |
| 自定义指令 › 快捷指令                       | 指令 CRUD              | `dela.chat.listCommands()` / `saveCommand()` / `deleteCommand()`                                                          | 自定义 / 指令（prompt）在 composer 输入 / 时手动触发，只在该轮生效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Skills                                      | 发现与启停             | `dela.capability.listSkills()` / `setSkillEnabled(name, enabled)`                                                         | 列出工作目录 `skills/` 下含 SKILL.md 的文件夹（agentskills.io 规范，主进程发现）；启停即时保存并返回最新列表（未知名抛错，失败回滚）。Skill 由文件系统管理，页面不提供删除——移除文件夹即删除，空态说明发现方式并支持手动刷新。                                                                                                                                                                                                                                                                                                                                        |
| MCP Server                                  | 服务器增删改与连接检测 | `dela.capability.listMcpServers()` / `addMcpServer()` / `updateMcpServer()` / `removeMcpServer()` / `refreshMcpServer()`  | 仅支持 stdio 服务器（command/args/env 持久化于主进程，视图不含配置与凭据）。`McpServerView` 带 connecting/connected/disconnected/error 状态、工具数与错误消息（error 卡内展示摘要并可重连）；启停/改配置经 `updateMcpServer`（改配置重连），`refreshMcpServer` 显式重连。添加、改配置或重连后页面在 connecting 状态下 500ms 短轮询至多两次使状态落定；编辑表单因视图不携带现值采用“留空保持原值”的部分补丁。删除走 radix 确认对话并说明后果。                                                                                                                         |
| 关于                                        | 版本与致谢             | `window.dela.version`（preload 内联 package.json）                                                                        | 只读展示版本与致谢名单（`credits.ts` 随源码打包，更新走 PR + 发版）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 隐私条款                                    | 只读说明               | 无 IPC                                                                                                                    | **占位页**：按当前实现描述数据存放位置、凭据加密方式、运行 Agent 时外发的内容、联网出口（含自建搜索实例）与不存在的功能；正式条款未定，页面自述「随实现更新、非正式法律文本」。                                                                                                                                                                                                                                                                                                                                                                                       |

模型供应商的 `verify()` 在沿用存储密钥时，main 要求 API 地址与已保存地址一致，并使用存储地址发送请求；更改地址后的检测与 `save()` 均要求显式填写密钥，末尾斜杠差异除外。详情异步保存完成时，只有用户仍停留在原详情才切换选中项，保留后来打开表单的草稿。

快捷键录制与单条恢复默认对完整候选键位表检查冲突；数字组展开 1…9 后比较，任意一档冲突均拒绝写入。

设置入口由全局搜索（Ctrl/⌘+K）提供：`features/settings/search-index.ts` 单一关键词表按分类聚合（分类名 + 摘要 + 选项标题与关键词），选中后跳转对应分类；设置页内不再设独立搜索框。快捷键本身可在「设置 › 快捷键」中修改，因此全局搜索的键位以该页当前值为准。
