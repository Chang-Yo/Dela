# 响应式设计的设计原则

**重点关注由于屏幕尺寸变化带来的布局的破坏：比如溢出，重叠，挤压等等**

## 宽屏和超宽屏

1. 内容不需要沾满全部宽度，人的视觉范围主要聚焦在中间部分，建议设计`max-width`，当宽度已经十分大时，左右两边可以接受大量留白
2. 若存在水平导航栏，一般宽屏状态可以全部展开
3. 对于纵向排列的内容，可以考虑将一列变为两列，将标题作为单独的一列，内容作为相邻的一列

## 窄屏（移动式设备）

由于屏幕宽度较窄，人们阅读的方向总是自上向下滑动的，这对于布局和动画的设计有着重要提醒。

1. 若存在水平导航栏，建议使用“汉堡菜单”聚合入口
   - 如果位置在右上角，建议导航面板从上往下展开，或者从右往左展开
   - 如果位置在左上角，建议导航面板从左往右展开
   - 如果位置在底部，建议导航面板从下往上展开
2. 检查间距是否根据页面宽度变化，尤其是：
   - Button中文字左右的 padding
   - 同类组件之间的 gap
   - 组件与屏幕边界之间的 padding
3. 检查水平排列宽度不足时的处理
   - 当group的元素宽度较大时，是否有滚动时的设计，或者自动分行排列
   - 考虑多个元素占一行变为每行一个元素
4. 字体的缩放
   - 标题大小建议在正文的 1.3-1.7 倍，不可以盲目的继承 `XX rem` 大小
5. 设置最小宽度
   - 当存在组件宽度随着屏幕缩放时，需要设置最小宽度，防止缩放过小。如侧边栏需要有最小宽度

## 中屏（平板电脑设备）

当没有特别要求时，平板设备可以理解为窄屏和宽屏的结合，可以取临界值然后粗暴分类为窄屏和宽屏。

1. 水平导航栏建议作为动态响应式，根据宽度动态展示需要的 nav item
