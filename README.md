Dela 是为上海交通大学学生打造的本地优先桌面工作台：把 Canvas 课程资料、校园邮箱、课表、水源社区聚合到一个应用里，再以「项目」为单位组织资料、笔记与 AI 助手对话。所有数据保存在本机（SQLite + 磁盘文件），凭据经系统密钥加密，界面行为向 VS Code 与 ChatGPT 等成熟产品的交互习惯看齐。

> _The world keeps changing. Dela stays with you._

Dela 以单实例运行：重复启动快捷方式会打开已有主窗口。关闭窗口后驻留系统托盘；左键单击托盘图标打开主窗口，右键单击显示菜单，可从菜单退出应用。

## 功能一览

拖拽标签时，分屏预览以半透明遮罩显示松手后将占据的半屏范围；靠近正文边缘才触发分屏，跨组中央表示移入该组。预览不改变正文背景或标签栏，拖拽结束或取消后自动清除。

标签最小宽度为 8rem，分屏面板在空间足够时至少保留 240px。源码、代码和纯文本默认不自动换行，可用 Alt+Z 或“视图 → 自动换行”切换；开关仅影响显示，不修改文件中的换行符。非 Markdown 内容靠左显示，代码行号区用浅灰背景及细分隔线区分；Markdown 笔记保留居中排版。

目录树的选中背景随文件层级缩进，层级线和背景采用浅色提示；活动标签顶部显示细横条，非聚焦分屏组的横条减淡。笔记和源码文档操作栏左侧显示“项目 › 文件夹 › 文件”的面包屑路径，长路径截断后可悬停查看完整路径。

历史对话列表不显示日期，仍按最近更新排序。每个项目（包括随聊）复用一个尚未发送消息的新对话，反复新建回到该入口，保留输入草稿；发送首条消息后可以新建下一个对话。侧栏会话行悬停显示置顶和归档按钮、完整标题及所属项目卡片；置顶项目和会话集中在“项目”节上方。项目菜单支持置顶、编辑名称、自定义分组、打开本地文件夹、归档全部对话和隐藏项目入口，隐藏入口可从设置恢复。

归档需要点击两次：第一次显示红色“确认归档”，第二次执行，点击别处取消。归档后保留消息与项目归属、关闭相应标签并从日常历史隐藏；“设置 → 已归档”按项目归类查看，可搜索、按项目筛选、恢复或二次确认后永久删除（含全部删除）。永久删除无法撤销，归档不会停止正在执行的任务。

如果系统无法解密已保存的凭据，可在设置中重新配置模型或服务连接；重新保存前会备份不可读的原密文。缺少邮箱凭据时会显示重新登录入口，同一账号登录后仍可使用原邮件缓存，无需清空聊天、项目或笔记。

启动后直接进入首页聊天，不必先选择项目；随聊（无项目）会话不入侧栏项目树，经首页与全局搜索可达。输入框底部可以选择项目，侧栏也可以进入项目与历史会话。项目行悬停或键盘聚焦时显示项目菜单与新对话按钮，菜单提供打开项目文件、创建对话和重命名；没有历史会话的项目展开后也可直接创建首个对话。工作台中聊天、笔记与预览共用标签：拖动标签可以排序、跨组移动或在正文边缘创建上下/左右分屏，拖动分隔线调整尺寸。组工具栏只常驻向右分屏；空组隐藏功能键，关闭或移走最后一个标签会自动合并布局。

「TODO」位于水源下方，可管理个人待办并查看 Canvas 作业完成状态。点击条目从底部滑出详情卡片：作业描述（与资料面板的作业模块同源）、截止时间与状态一目了然，可直接跳转 Canvas；悬停条目浮现行尾快捷操作，个人待办可完成、写入日历、编辑、删除。新建与编辑共用从工作区底部滑出的面板：步进式选择截止时间、挑选颜色，并可一键「写入日历」，让待办按截止时间显示在课表周/月视图中。作业在应用运行时每 15 分钟刷新，也可手动同步；已读与完成独立，首次导入不刷历史通知，后续新增作业只提醒一次。支持全局搜索和 AI 待办工具，暂不支持在 Dela 中提交作业。

**本地优先与安全边界**：数据与索引保存在本机 SQLite，凭据经 Electron `safeStorage` 加密；邮件 HTML 与社区内容在禁止脚本的沙箱 iframe 中渲染；渲染进程不接触文件系统、数据库与凭据，一切经受控 IPC 通信。发送给模型服务商的内容范围在界面上始终可见。

模型供应商更改 API 地址时，检测和保存都需要重新填写 API Key，避免把已保存密钥发送到其他地址。

编辑器热修复（0.7.1，2026-09-21）：已修复中文选词后被旧拼音覆盖、源码输入被清空的正文同步问题，回归测试通过，用户已确认修复有效。

## 下载安装

从 [Releases](https://github.com/Chang-Yo/Dela/releases) 下载对应平台安装包（公开镜像：[Chang-Yo/Dela_releases](https://github.com/Chang-Yo/Dela_releases)）：

| 平台    | 系统要求                          | 产物               |
| ------- | --------------------------------- | ------------------ |
| Windows | Windows 10+ (x64)                 | NSIS `.exe` 安装包 |
| macOS   | macOS 13+ (Intel / Apple Silicon) | `.dmg`             |

> Linux `.AppImage` 暂时停止分发（CI 不再构建 Linux 安装包），恢复后重新上线。

> 项目处于早期开发阶段（v0.x），安装包尚未做代码签名，Windows 可能出现 SmartScreen、macOS 可能出现 Gatekeeper 提示，选择「仍要运行」即可。

## 本地开发

需要 Node.js **24.21.0** 与 pnpm **12.3.4**（本机可用 `. ./scripts/use-local-tools.ps1` 启用仓库内固定版本）：

```sh
pnpm install
pnpm dev
```

| 命令                | 用途                                                  |
| ------------------- | ----------------------------------------------------- |
| `pnpm dev`          | 启动开发服务器和窗口，监听主进程/preload 变更         |
| `pnpm build`        | 类型检查与 main/preload/renderer 三入口生产构建       |
| `pnpm test`         | Vitest 单元测试                                       |
| `pnpm smoke`        | Electron 内 SQLite、React 渲染与 preload 隔离冒烟检查 |
| `pnpm package:dist` | 生成当前平台安装包                                    |

环境搭建细节、冒烟测试与代码组织约定见 [开发指南](docs/development.md)；版本与发布流程见 [发布指南](docs/release.md)。
