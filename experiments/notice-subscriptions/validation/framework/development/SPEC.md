# 独立框架开发语料

本语料依据“用户 URL → 候选确认 → 规则重放 → 身份增量”的行为契约构造。先创建独立记录模型，再渲染页面或 feed；期望值来自记录模型，不从 HTML 反向抽取。生成过程不导入、不运行待测实现，也不读取已有测试、黄金结果或其他确认集。

## 范围与判分

`corpus.json` 顶层为 case 数组。每个正例要求至少一个候选准确覆盖期望记录，标题、绝对 URL、发布日期均相同，不能额外混入相邻栏目、导航、图片链接或响应式副本。记录按首次出现顺序保留、按绝对 URL 去重，置顶重复不改变已出现记录位置。默认期望按顺序比较；评估方若另报集合覆盖率，应与严格成绩分列。

首选候选成功率、全部候选覆盖率、提供完整 `sampleTitle` 后的辅助成功率分别报告。`sampleTitle` 是该案第二条通知的完整标题，不是选择器或站点知识。负例要求零候选，不是仅要求“首选候选不存在”。

每个正例包含三种重放：外观变化必须相同；相邻栏目或协议元数据变化允许显式拒绝或准确相同，禁止静默混栏；新增通知并移除最旧一条必须准确得到新的期望记录。后者用于验证规则可重用和新增身份边界，不能复用旧的记录快照作为解析结果。重放的 `equal` 对照 `transform.expected`，未指定时对照基础 `expected`；`reject-or-equal` 只允许显式失败/拒绝或完整精确结果。显式拒绝仅计入安全通过，不能计入兼容成功。

## 数据约定

- 六个正例族：`li`、`table`、`article` 卡片、`dl`/`dt`/`dd` 各 22 案，原生 RSS 与原生 Atom 各 12 案，共 112 个正例。另有 12 个负例，总计 124 案、336 个重放。`table` 族除特意检验随机 class 的场景外不带 class。
- URL 使用保留的 `.invalid` 域，各案不同域；不要求联网。路径包含普通相对地址、`base`/`xml:base`、查询参数、无扩展名详情页。只接受 HTTP(S) 公告详情身份。
- 所有标题不少于八字，完整标题是明确的通知内容；实体解码和内联元素分割不改变标题。标题仅归一化空白，不删除前后标点；括号、“第几项”等明确属于标题。置顶标记在标题链接外，不能附加到标题。标题中会议日期不等于发布日期。
- 明确日期统一为 UTC ISO 字符串。仅年月日按约定归一化为当日 `00:00:00.000Z`，因此黄金仍是完整 ISO 而非 `YYYY-MM-DD`；显式 `+08:00` 时刻转换 UTC，须完整比较时刻，不仅比较日期。若统一评价器支持日粒度黄金，只有黄金本身为 `YYYY-MM-DD` 时才按日比较，本集不使用此缩写。没有发布日期时为 `null`，不猜年份、不使用抓取时间、更新时间、活动时间、feed 级时间补全。RSS `pubDate`、Atom `published` 为发布依据；Atom 只有 `updated` 时仍为 `null`。预览与规则重放应逐字段一致。
- 基础列表 3–6 条记录。组合覆盖无日期、文字发布日期、重复置顶、隐藏响应式副本、相邻新闻、导航、嵌套 role/id tabs、标题日期、活动时间、装饰 class、同 URL 图片/标题、实体、嵌套标题、摘要、最后更新和时区。
- feed 保持原生协议结构，仅使用 12 个适用于协议的日期、相对地址、重复、标题日期、图片 enclosure、实体、查询地址、部分缺日期、摘要、更新时间与时区场景；不把 HTML 的 tabs、class、导航复制为额外 feed 案例。整个集合仍不能解释成 124 个真实站点。

负例包括密码登录、登录入口、纯导航、带日期历史导航、单篇正文、正文引用链接、危险/非网页协议、空 SPA、加载中 SPA、占位锚点、空 RSS。不要求执行任意 JavaScript、登录、分页或自动推测接口。

## 冻结与局限

使用现有 Node 24 直接运行 `node experiments/notice-subscriptions/validation/framework/development/generator.ts`。没有安装依赖。生成器自检数量、唯一 ID、完整标题、HTTP(S) 绝对地址和规范 ISO 日期，然后输出 `corpus.json` 与 `freeze.json`。冻结文件包含语料、生成源、本文和独立期望摘要的 SHA-256，且声明待测算法未运行。应在首次评估前保存这些哈希；评估后修改期望应创建新版本，不能原地追认失败输出。

这是可见开发集，不是对未见真实网站准确率的估计。布局虽有组合，仍由有限生成器共享骨架；没有真实服务端响应、编码异常、网络错误、JavaScript 水合、认证、分页或抓取时区猜测。`dl` 使用 HTML 允许的分组 `div`。隐藏副本以标准 `hidden` 标记，无法代表所有 CSS 媒体查询。相邻栏目正确选择依赖清晰栏目语义与完整标题辅助，不要求推断用户没有表达的栏目偏好。
