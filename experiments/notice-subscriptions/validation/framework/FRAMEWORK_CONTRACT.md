# 通用订阅框架契约

本模块处理公开 URL 的获取、候选发现、用户确认后的规则重放和新增身份计算。CLI 是一个宿主；其他 Node/Electron 宿主可直接调用同一组函数，不需要学院目录、逐站选择器或插件注册中心。正式应用 UI、调度器、收件箱和可靠投递由宿主实现，不是解析核心的隐含能力。

| 阶段 | 可复用接口                               | 宿主责任                                                                                                              |
| ---- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 获取 | fetchNoticePage；renderNoticePage        | 选择 HTTP 或显式渲染；保留最终 URL、编码和获取模式。渲染会执行页面脚本，不能悄然替代 HTTP。                           |
| 发现 | analyzeNoticePage                        | 展示候选及诊断，让用户明确选择；score 仅用于排序，不是正确概率。完整标题可辅助定位，不是逐站配置。                    |
| 确认 | extractNoticeEntries；updateSubscription | 在同一输入上重放用户选定规则后建立静默基线；将规则、acquisition、seenIds、checkedAt 一起保存。                        |
| 刷新 | extractNoticeEntries；updateSubscription | 重载并验证 JSON 状态，沿用获取模式；最终 URL 或栏目失配需重新确认；出错不提交新状态。先成功交付输出，再保存已见身份。 |

`noticeRuleSchema`、`subscriptionStateSchema` 用于外部持久化数据入口；内部传递已验证的类型。发现和重放共用条目提取。更新函数返回新状态，不修改传入状态，也不执行文件写入或发送通知。条目按 URL 身份去重，查询参数保留；仅明确的同文档文章锚点保留 fragment。标题修改、置顶和顺序变化不会产生新身份。

发布日期未知时保持 null，不从抓取时间、活动日期或更新时间补全。日粒度数据保留日期；明确带时区的机器 datetime 保留 UTC ISO 时刻。原生 Feed 继承 xml:base。调用方应按时间精度显示，不能把 UTC 时刻直接截断当作任意地区的当地日期。

跨宿主渲染使用 `renderNoticePage(url, timeoutMs, { electronPath, workerPath })`，两个资源路径均须为绝对路径。提供该参数后不依赖 cwd 查找资源；宿主负责构建并分发 worker 与 Electron。省略参数仍保留实验 CLI 的项目根目录约定，不代表已经提供独立安装包。

HTTP/渲染有体积和时间预算；候选稳定不证明未知异步批次齐全。没有可靠目标时可拒绝并要求重新确认；拒绝属于安全结果，不是兼容成功。iframe、登录、验证码、任意 onclick 程序、SPA hash 路由及自动分页仍不保证。先输出后保存状态提供至少一次重试语义，不是跨文件事务或 exactly-once。
