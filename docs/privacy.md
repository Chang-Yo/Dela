# Dela 隐私条款

本页说明你的数据存放在哪里，以及哪些内容会离开你的设备。使用本软件时的责任划分见[《Dela 使用条款》](https://dela.changyo.me/terms)。

最后更新：2026-10-23

## 1. 数据保存在本机

**本软件没有远程数据库，也不把你的数据上传给开发者**。你的对话、资料与各项设置都保存在你的设备上。界面不直接读写数据库与凭据文件，只通过预加载接口请求主进程。

应用数据目录（Electron 的 userData，Windows 上通常是 %APPDATA%\Dela）下：

- SQLite 数据库 dela.db：会话索引、邮件与课程等同步数据、笔记与文件的索引、通知、各项设置，以及条款接受记录（哪一份、哪一版的条款，以及接受时间与应用版本）。
- 对话的完整记录：pi/sessions 下的 JSONL 文件，由 Agent 内核写入；数据库里只有这些会话的索引。
- 其他文件：对话中发送的图片与文档附件副本（chat-media/）、邮件草稿（mail-drafts/）、远端项目的内容镜像（remote-context/），以及旧版数据库的整库备份（dela-legacy-backup.db）。文档副本保留供后续追问，启动时清理没有会话引用的图片与文档；未发送的文档附件在你移除时删除。
- 界面状态：Chromium 的 Local Storage（userData/Local Storage）里存着侧栏与各面板的折叠状态和宽度、已看过的更新版本、主题与字号、聊天草稿，以及引导步骤与你的同意标记。
- 你主动导出的备份：在条款接受页选择位置后，主进程把应用数据、工作目录与你自己的 Skill 复制过去（跳过可再生的 Chromium 缓存，数据库取一致快照）。这是一次本地文件复制，不联网；副本里含有凭据文件与数据库，请保存到你信任的位置。

同一目录下的加密凭据文件：

| 凭据文件             | 保存的内容                          |
| -------------------- | ----------------------------------- |
| llm-providers.bin    | 模型服务地址与 API Key              |
| mail-credentials.bin | 邮箱地址与密码                      |
| canvas-token.bin     | Canvas 访问令牌                     |
| shuiyuan-key.bin     | 水源 User API Key、用户名与绑定时间 |
| campus-session.bin   | 教学信息服务网的登录会话 Cookie     |

旧版单凭据文件 model-credential.bin 在升级为多提供商配置后自动删除。

工作目录（默认「文档/Dela」，可在 设置 › 工作区 更改）中的文件：笔记的 Markdown 正文与其中的图片、导入的文件、从 Canvas 下载的课程文件（courses/），以及导出到「预览导出」文件夹的 PDF。

开启 Pi packages 时：登记的包（来源、启停、资源开关）存在数据库里；从 npm 或 git 安装的包在应用数据目录的 pi/npm 与 pi/git 下，本地目录来源不复制、只登记路径；本机没有 npm 时下载的 Node 运行时在 components/node 下；包注册的 MCP 服务器的连接日志在 pi/mcp.log。Dela 不读写你自己的 ~/.pi 目录，只有一个例外：包注册的、需要 OAuth 登录的 HTTP MCP 服务器，其登录凭据由 Pi 存在 ~/.pi/agent/mcp-auth.json。

可选文档解析组件保存在应用数据目录的 components/document-reading 下。文档读取任务的输入副本与提取结果保存在系统临时目录的 dela-document-reading 下，读取结束后清理；异常退出留下的任务会在下次准备文档时清理超过 24 小时的部分。

邮件、课程、课表与作业是学校服务的本地副本，可重新同步获取。邮箱密码不写入数据库：数据库里只有邮箱地址、服务器与端口。

## 2. 凭据如何保护

- **凭据文件用 Electron safeStorage 加密后写入，解密能力由操作系统保管**；系统不支持加密时，应用拒绝读写并给出提示。
- 写入先落临时文件再原子替换；旧文件无法解密时，先备份为「原文件名.unreadable-随机串.bak」再写入新内容，不因重新配置而删除。
- **API Key 与令牌只在主进程内使用**：界面拿到的模型服务配置不含密钥字段；邮箱、Canvas 与水源只返回连接状态、邮箱地址或用户名，不含密码与令牌。
- **密钥不进入模型消息**：请求时由主进程把 API Key 放进 HTTP 请求头，发给模型的内容是对话与资料文本。

## 3. 运行 Agent 时发送到模型服务的内容

**只有在你发送消息、让它继续执行，或在设置中检测密钥时，才会请求模型服务**。请求由主进程直接发出，界面不持有密钥。

- 系统提示词，以及已启用 Skills 的名称与描述索引。
- 你在 设置 › 自定义指令 中填写的全局指令（留空则不发送），它会随每次请求一并发出。
- 当前会话的历史消息；较早历史已生成摘要时，摘要一并发送。
- 本轮引用的资料内容（按需读取的笔记、课程文件、邮件等正文）、附件正文、你输入的文字与图片。
- 工具执行结果会随后续轮次继续发回同一服务。

这些内容发往 设置 › 模型供应商 中启用的地址。**数据保存在本机不等于在本机推理**：应答由你选择的模型服务产生，内容发出后如何保存由该服务决定，本应用不控制。

**已启用的 Pi package 不受上述清单约束**。包里的扩展与本软件同进程、同权限运行，能读到本机文件、数据库与解密后的凭据，可以自行联网，它发出什么、发往哪里由包作者决定，本软件不代理、不记录也不拦截。扩展还可以向会话写入消息、调用模型或修改发给模型的内容。是否启用一个包，请先确认它的来源与源码。

## 5. 本机记录了什么

**应用运行时不写日志文件**（开发模式的控制台输出只打印在终端，不落盘）。Agent 执行也不单独留档：一次执行的运行状态只存在于内存与界面（导航行上的运行标记），执行过程随对话正文一起写进会话文件（见第 1 节），数据库里的会话索引只记消息计数与最后更新时间。

凭据与密钥不写进会话记录，也不会作为上下文发给模型。

## 6. 本软件没有的功能

- **没有账号服务器**：不需要注册或登录 Dela 账号，代码中也没有把数据上传到项目服务器的接口。
- **没有云同步**：换一台设备不会自动带上你的数据，迁移需要自行拷贝工作目录与应用数据目录，或使用条款接受页里的导出。
- **没有使用统计与崩溃上报**：依赖中没有统计分析或崩溃上报的第三方服务，主进程的对外请求只有上面列出的几类。
