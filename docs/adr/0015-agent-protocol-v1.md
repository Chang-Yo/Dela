# 0015. Agent 协议 v1 以单用户为前提

- 状态：已接受
- 日期：2026-11-12
- 取代：[0004](0004-agent-protocol.md) 中「协议从第一版起具备」一节

## 背景

0004 要求第一版协议就具备事件序号、多客户端并发规则和「不传本地路径」。实际使用场景是一个用户、多台设备、同一时刻只用一台：电脑和手机同时操作同一个会话几乎不会发生。为这种情况设计锁、序号和路径改写，会让协议变复杂，收益却很小。

## 决定

协议定义在 `core/protocol/agent.ts`，以 zod 为唯一来源，`shared` 里的会话类型由它推导。v1 只做下面这些：

- **没有多端规则**：任何一端都能取消和撤回，事件推给所有已连接的端，不记录 run 由哪一端发起。
- **不加事件序号**：会话快照和流式事件都是整条覆盖，不是增量。重连后重新订阅，再取一次快照即可。
- **本地路径照传**：`cwd`、`@` 引用和轮次改动里的路径保持原样，不做清洗和还原。
- **版本握手**：`handshake` 只比对一个整数主版本，不一致就拒绝连接。只做新增时不升版本。
- **范围**：会话、提问与插队、取消与撤回、后台任务、分支、模型选择、斜杠命令、旁问、附件、轮次改动和推送事件。模型只能在桌面端配置，协议只提供已配置好的模型列表。置顶、归档、导出、删除、原生对话框、打开本地文件、Git 审阅和自定义命令的增删都属于桌面私有功能。

`@` 文件候选和统一的 `Reference`（AD-8）暂不进入协议，以后以新增的方式加入。

## 后果

- 协议保持精简，桌面端改动成本低。
- 两端同时操作同一个会话时，结果以最后到达的操作为准，不做冲突处理。
- 手机端拿到的路径是桌面上的路径，只能用于展示，或者原样回传给桌面。
