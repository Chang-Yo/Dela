# 0012. 跳转目标由页面所属的模块登记

- 状态：已接受
- 日期：2026-11-10

## 背景

全局搜索、通知、Agent 的引用都需要“打开某个页面”。如果在一个中心文件里列出所有页面和参数，每个新页面都要改这个文件；如果各自定义，同一个页面会有几种不同的参数写法。

## 决定

- `app/module.ts` 声明一个空接口 `NavTargets`。页面所属的模块用 TypeScript 接口合并登记自己的页面和参数，例如 `mail: { messageId: number }`。
- `NavTarget` 由 `NavTargets` 推导，是所有已登记页面的联合类型。搜索结果、通知等只携带 `NavTarget`，不认识具体模块。
- 过渡期内，尚未迁移的页面集中登记在 `shared/nav-targets.ts`，页面迁入 `modules/` 时随之搬走。

## 后果

- 新增页面只改自己的模块；跳转参数写错时编译失败。
- 接口合并只在声明文件被同一个 tsconfig 包含时生效。登记所在的文件必须同时出现在 main 和 renderer 的 tsconfig 中。
- 打开页面的实现目前仍在 `App.tsx` 中按 `page` 分支，导航路由（0009）落地后改由路由处理。
