# 0006. 数据所有权与移动端的边界

- 状态：已接受
- 日期：2026-11-09

## 背景

移动端只转发 Agent 对话，学校功能在移动端另行实现。如果不划清数据归属，两端会各自维护一份 Dela 自己的数据，最终出现冲突。

## 决定

| 数据                       | 归属             | 访问方式                            |
| -------------------------- | ---------------- | ----------------------------------- |
| 会话、Agent 运行、项目文件 | 桌面端 core      | 桌面端和移动端都通过 Agent 协议访问 |
| Todo、个人日程、笔记、草稿 | 桌面端的各个模块 | 只在桌面内部使用，不进入协议        |
| Canvas、邮件、课表、水源   | 学校服务器       | 桌面端和移动端各自直连学校          |

移动端独立实现的功能，只能是直接读取学校服务器的功能。属于 Dela 自己的数据，不能在移动端另起一份。

## 后果

- 移动端通过对话就能使用桌面端的全部校园能力，因为 Agent 在桌面上运行。
- 学校接口在 TypeScript 和 Dart 中各实现一份。这是有意的重复：跨部署单元时，重复比耦合更好。
- 如果以后移动端需要直接查看 Todo，需要新增一条记录，决定是否把它纳入协议。
