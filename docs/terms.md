## 1. 软件性质

本软件是一款在本地运行的桌面应用，用于管理校园信息、编辑文档、运行终端，以及调用人工智能 Agent 完成工作。**本软件没有账号系统，没有服务端，也没有远程数据库，你的数据保存在你自己的设备上。**

**本软件自身不提供任何网络服务**，不运营承载你数据的服务器，也不代理、转售或转授任何第三方服务。开发者无法访问你的数据。
