# REQ-0003 Canvas 课程文件批量下载

## 需求

- 场景：资料页中的 Canvas 课程文件目前主要供在线浏览，逐个保存不方便，需要把一门课程或一个文件夹的资料一次下载到本地。
- 期望：支持按课程和文件夹批量下载；下载前由用户选择保存目录，保留 Canvas 中的课程目录结构，并显示下载进度和失败项。

## 验收

- [ ] 用户可以对整门 Canvas 课程或选定文件夹发起批量下载。
- [ ] 每次下载前可以选择本地保存目录，下载结果保留原课程与文件夹层级。
- [ ] 下载期间可以看到进度，完成后能区分成功和失败的文件。
- [ ] 失败文件可以重试。
