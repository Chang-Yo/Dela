# Dela 需求管理

这里记录团队成员明确要求登记的需求。索引列出的文件才是有效需求；直接交给 Agent 实现的改动不自动建需求，完成后写入 `CHANGELOG.md`。

## 怎么写

- 每项需求一个 `REQ-xxxx-<slug>.md`，从 [template.md](template.md) 复制。
- 只写三部分：**需求**说清场景与期望，**验收**列出可检查的结果，**记录**保留提出时间和实现证据。
- 不填写负责人、优先级和目标版本；需要排期时由团队在讨论中决定。
- 如果“要做什么、为什么、怎样算完成”有缺失或歧义，Agent 先追问一至三个问题，再整理成文档，不自行补全关键事实。

## 状态

```text
todo → doing → done
  └────────→ cancelled
```

| 状态        | 含义                                  |
| ----------- | ------------------------------------- |
| `todo`      | 已记录，尚未开始                      |
| `doing`     | 正在实现                              |
| `done`      | 验收完成且已有 Commit / PR / 测试证据 |
| `cancelled` | 团队决定不再继续                      |
