# Dela 功能边界

通用原则：

不开发绕过学校官方流程、批量抢占资源或替代本人操作的自动化脚本，例如：

- 不开发利用脚本来自动预约场馆和校园活动的功能
- 不开发利用脚本来自动选课的功能

## 以下功能需要慎重讨论，不接受未提前讨论的相关 PR

- 交大选课社区的功能：Dela目前并没有和选课社区官方达成任何正式的合作，暂时不考虑加入相关的功能；如果您能够联系选课社区官方并能够为Dela的合作做出贡献，请首先联系项目作者 @Chang-Yo (huzhixi1116@gmail.com)
- 传承交大的功能：Dela目前并没有和传承交大官方达成任何正式的合作，暂时不考虑加入相关的功能；如果您能够联系选课社区官方并能够为Dela的合作做出贡献，请首先联系项目作者 @Chang-Yo (huzhixi1116@gmail.com)
- Linux平台适配：Dela团队目前还没有计划适配Linux平台，如果您可以为Linux平台做出贡献并能够长期维护Linux平台分发，请先联系作者
- 全面的代码编辑功能：Dela 不以成为通用 IDE 为目标，Dela的定位是面向学习场景，专为交大在校生研发的 Agent，最终的目标是「通用Agent」
- 云同步功能：Dela目前定位是桌面运行的本地应用，暂不考虑连接私有服务器实现云同步的功能
- 更全面的水源社区功能：Dela不打算复刻一个完整的水源社区，水源社区的模块必须服务于Dela产品自身的定位和功能，同时受限于实际可获得接口的完整性
- 账号认证功能：Dela是交大学生独立开发的产品，和学校无互相隶属关系，所以Dela暂时没有接入 jAccount 功能，也暂不考虑账号的认证存储功能
