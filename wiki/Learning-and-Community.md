## Canvas 在线教学平台

**服务能力**

Canvas 提供个人课程、课件、作业、提交记录、课程模块、讨论和成绩等教学数据。个人账号实测覆盖 5 个学期、48 门课程。

**凭证如何获取**

1. 打开[交大 Canvas](https://oc.sjtu.edu.cn/)并登录本人账号。
2. 点击头像进入“设置”。
3. 在“允许融入使用的外部软件”区域选择“创建新的访问许可证”。
4. 填写用途和有效期，生成个人 Access Token。
5. 立即复制并保存 Token。Canvas 通常只在创建时完整显示一次。
6. 后续请求将该 Token 作为 Bearer 凭证发送。

Canvas 个人数据 API 的基础地址为 <code>https://oc.sjtu.edu.cn/api/v1</code>。

**数据如何获取**

1. 读取课程列表，并同时请求课程所属学期和个人选课信息。
2. 按 term 字段划分学期。历史课程可能长期保持 available，不能只靠课程状态分类。
3. 对每门课程分别读取文件夹、文件、作业、提交、模块、讨论和公告。
4. 文件夹接口返回扁平列表，需要依据 parent_folder_id 还原目录树。
5. 作业截止时间以 due_at 为准。跨课程待办需要遍历各课作业后自行聚合。
6. 所有列表按照响应中的 Link 分页继续读取。交大实例实测每页最多返回 50 条。
7. 下载课程文件时，先访问 Canvas 返回的下载地址，再跟随跳转取得对象存储的临时地址。
8. 单门课程的 401 或 404 不应阻断其他课程同步。

**可获得的数据范围**

- 当前和历史课程
- 课程名称、课程代码、所属学期和选课状态
- 课程文件及文件夹结构
- 作业要求、截止时间、分值和提交方式
- 本人的提交状态、成绩、评语和提交附件
- 课程模块及学习顺序
- 讨论、公告和回复
- 教学大纲
- 部分课程成绩信息

课堂录像不属于 Canvas 文件接口，需要通过独立的课堂视频服务取得。

**可以构建的服务**

- 按学期和课程整理的课件中心
- 课程资料批量下载和离线归档
- 跨课程作业日历与提醒
- 作业提交状态和成绩面板
- 按课程模块组织的学习导航
- 课程资料全文搜索
- 基于课件、作业和讨论的个人问答
- 个人提交文件归档

**服务入口与参考资料**

## 本科教学信息服务网与个人课表

**服务能力**

本科教学信息服务网提供个人课程和课表。开发者可以复用本人登录后的教学网会话读取个人课表，也可以通过获批的 Education API 取得课表数据。

**凭证如何获取**

个人会话路线：

1. 打开[本科教学信息服务网](https://i.sjtu.edu.cn/)的 jAccount 登录入口。
2. 由用户完成人工登录或扫码登录。
3. 登录成功后，教学信息服务网在当前浏览器会话中保存 Cookie。
4. 后续课表请求必须复用同一会话。

Open API 路线：

1. 申请 jAccount 应用接入。
2. 申请 Education API 所需的 lessons scope。
3. 让用户通过 OAuth 授权码流程登录并授权。
4. 使用授权码换取 Access Token。

**数据如何获取**

个人会话路线：

1. 按“学年—学期”把学期转换为教学网使用的学年和学期代码。
2. 请求个人课表查询页面对应的数据接口 /kbcx/xskbcx_cxXsgrkb.html。
3. 请求中携带学年、学期和当前教学网会话。
4. 读取返回的课程列表和校历周次信息。
5. 将周次表达式展开为具体教学周，再按星期和节次生成日历事件。
6. 返回登录页或非预期页面时，重新完成 jAccount 登录。

Open API 路线：

1. 使用带 lessons scope 的 Access Token 调用学生课表接口。
2. 按接口文档提供学生身份和学期参数。
3. 读取课程、教学班和排课信息。
4. 需要教学班详情时，再按教学班编码或 bsid 查询。

**可获得的数据范围**

- 学年和学期
- 课程名称和课程代码
- 教学班名称和标识
- 教师
- 学分
- 校区和教室
- 星期和节次
- 上课周次
- 选课备注

Education API 还公开教学班、考试和绩点相关接口，具体可用字段以应用获批 scope 和接口响应为准。

**可以构建的服务**

- 个人课表
- 周视图和月视图日历
- 上课地点与时间提醒
- 课程冲突检查
- 课表导出
- 课程与 Canvas、课堂视频资料的关联索引
- 考试和成绩工具

**服务入口与参考资料**

- [本科教学信息服务网](https://i.sjtu.edu.cn/)
- [Education API](https://developer.sjtu.edu.cn/api/education.html)
- [Open API 概述](https://developer.sjtu.edu.cn/api/overview.html)
- [本科教学数据资源 API](https://developer.sjtu.edu.cn/graphql/student.html)

## 课堂视频

**服务能力**

交大视频平台提供本人教学班的录像、双路视频、课程时间、机器转写、知识点总结和 PPT 页面。2026-10-06 的个人账号实测覆盖课程发现、录像、转写、总结和课件数据。

**凭证如何获取**

1. 打开[交大视频服务](https://v.sjtu.edu.cn/)。
2. 选择 jAccount 登录。
3. 由用户完成人工登录或扫码登录。
4. 登录成功后，视频平台在浏览器会话中保存校园登录 Cookie。
5. 调用用户信息接口检查当前会话；能够返回本人身份信息时，登录有效。
6. 课堂录像接口复用这套会话，不需要 Canvas Access Token，也不需要门户使用的 JWT。

**数据如何获取**

1. 读取当前学期列表，确定当前学期标识。
2. 按学期读取本人课程安排，取得教学班 ID、课程代码和课程名称。
3. 如果课程安排列表为空，可以读取“我的课程”列表，并按学期筛选。
4. 使用教学班 ID 查询该课程的录像场次。
5. 对每个场次读取上课时间、教室、节次、教师、时长和缩略图。
6. 按场次 ID 取得两路 MP4 视频地址。
7. 读取逐句机器转写；每句话包含开始时间、结束时间和文本。
8. 读取 AI 知识点树、分段总结、PPT 页面、OCR 文本和翻页时间。
9. 视频直链包含临时签名，应在每次播放或下载前重新取得，不把旧直链作为长期地址保存。实测链接至少可用 8 小时，但平台没有公开固定时效。
10. 新录制课程的字幕、总结和 PPT 切片采用异步处理。读取场次中的转写和切片状态；尚未完成时保留场次，并在下次同步时重新检查。

学期切换不需要手工猜测学期编号：先读取 `/v1/list/termYear`，优先选择带 `currentTerm` 标记的学期；若平台没有返回该标记，再选择列表中的最新学期。随后用学期 ID 读取本人课程，备用课程列表也必须按同一学期 ID 过滤。

**可获得的数据范围**

- 教学班和课程信息
- 录像场次列表
- 上课日期、起止时间、教室和节次
- 教师、课程代码和课程名称
- 视频时长和缩略图
- 两路 MP4 视频地址
- 逐句机器转写及毫秒级时间戳
- 知识点树及视频时间范围
- 分段课程总结
- PPT 逐页图片、OCR 文本和翻页时间
- 播放次数和最近观看场次

课程是否录制以及转写、总结和 PPT 是否生成，取决于课程配置和平台处理状态。

**可以构建的服务**

- 按课程和日期组织的课堂录像库
- 双画面课堂播放器
- 带时间戳的字幕搜索
- 点击知识点跳转到视频位置
- PPT、字幕和视频同步浏览
- 根据课堂内容生成复习提纲
- 基于转写和 PPT 的个人课程问答
- 按关键词定位课堂讲解片段
- 个人课堂录像离线缓存

**服务入口与参考资料**

- [交大视频服务](https://v.sjtu.edu.cn/)
- [教育技术中心数字化教学环境](https://etc.sjtu.edu.cn/digital.html)
- [交大 Canvas](https://oc.sjtu.edu.cn/)

## 第二课堂

**服务能力**

[第二课堂平台](https://activity.sjtu.edu.cn/)提供活动发布、活动检索和学生报名。本轮验证确认个人资料和活动首页列表可以读取；活动详情、报名表和报名操作可从社区实现中看到，但尚未逐项实测。这些能力来自网页内部接口，不是公开开发者 API。

**凭证如何获取**

1. 打开[第二课堂平台](https://activity.sjtu.edu.cn/)并选择 jAccount 登录。
2. 由用户完成人工登录或扫码登录。
3. 登录成功后，活动平台在浏览器会话中保存站点令牌 `IMPSA-Token`。
4. 经用户授权的本地工具从本人已登录的浏览器 Cookie 中读取该令牌，并将它作为 Bearer Token 访问活动平台。
5. `JAAuthCookie` 只用于 jAccount 登录会话。本轮单独复用该 Cookie 时，授权请求会返回 jAccount 登录页，不能把它直接当作第二课堂接口凭证。
6. `IMPSA-Token` 失效后，重新登录活动平台取得新的令牌。

**数据如何获取**

1. 本轮已验证本人资料和活动首页列表，两个只读请求均正常返回。
2. 活动列表支持分页、活动类型和时间排序等查询条件。
3. 活动详情、报名状态和报名表字段来自社区源码，尚未逐项实测。
4. 报名或取消会改变个人记录，本轮没有执行。后续测试前应展示活动、时间、地点和报名表内容，并由用户确认。
5. 网页内部接口可能调整，客户端应明确报告令牌失效、字段变化和报名失败。

**可获得的数据范围**

- 已实测：本人资料响应、活动首页列表
- 源码可见但未逐项实测：活动详情、主办方、名额、时间、地点、报名表和报名状态
- 个人报名记录、签到、活动认定和第二课堂成绩：待进一步验证

**可以构建的服务**

- 活动发现和筛选
- 报名截止与活动日历提醒
- 报名表填写辅助
- 个人活动清单
- 第二课堂成绩或学时汇总

- [第二课堂平台](https://activity.sjtu.edu.cn/)
- [校内活动通知中的第二课堂报名入口](https://www.sjtu.edu.cn/tg/20240418/196322.html)

## 选课社区

**服务能力**

[选课社区](https://course.sjtu.plus/)是面向交大师生的课程点评与选课辅助社区。当前平台提供课程与教师检索、课程评价、评分趋势、关注课程、课程通知、个人课程和用户 API Key。它是社区服务，不是学校官方教学系统。

**凭证如何获取**

1. 使用交大邮箱注册或登录[选课社区](https://course.sjtu.plus/)。站点密码是选课社区密码，不是 jAccount 密码。
2. 登录后进入用户菜单中的“API Keys”页面。
3. 新建 API Key，并立即复制生成的 Key。明文只显示一次。
4. 将 Key 保存到本机凭证配置。工具将它作为 Bearer Token 发送给选课社区，服务器按 Key 所属用户的权限返回数据。
5. 不再使用时，从原页面删除该 Key。

用户 API Key 不是只读凭证。它还能以本人身份关注课程、发布或修改评价、投票等，只应配置给本人控制的可信工具。

**数据如何获取**

1. 本轮已验证账号身份和课程关键词搜索，两个只读请求均正常返回。
2. 当前 API 参考还列出课程详情、开课学期、教师组、评分趋势和评价列表。
3. 登录后可以读取本人课程、关注或忽略状态、本人评价、积分记录和站点公告；这些个性化接口尚未逐项实测。
4. 创建或修改评价、投票、关注、忽略和登记课程都会改变社区数据，本轮没有执行。实际操作前应展示目标并由用户确认。
5. 评价属于用户内容。做课程推荐时应同时展示评价数量、评价时间和教师信息，不能只按平均分排序。

**可获得的数据范围**

- 账号基本信息：用户 ID、用户名、邮箱和角色
- 课程名称、代码、院系、学分、语言、课程类别、面向年级和开课学期
- 教师与教师组，以及同代码或同教师的相关课程
- 评分均值、评分分布、评价数量和学期趋势
- 评价正文、学期、用户填写的成绩、投票和更新时间
- 本人的课程、评价、关注或忽略状态和积分记录
- 课程通知、个人设置和站点公告

评价中的成绩由社区用户自行填写，不是教学信息网的官方成绩。选课社区 API Key 也不会取得 Canvas、教学信息网或其他校园系统的数据权限。

**可以构建的服务**

- 课程和教师检索
- 同名课程与不同教师对比
- 课程评价摘要
- 结合课表的选课参考
- 关注课程和通知管理
- 用户确认后的评价与投票助手

## 传承·交大

**服务能力**

[传承·交大](https://share.dyweb.sjtu.cn/)是课程资料共享平台，提供课程检索和资料浏览。服务页面还提供上传、积分兑换、下载、评价、评论和举报等操作；本轮只验证课程详情和资料列表。资料由用户上传，不代表教师、学院或学校部门背书。

**凭证如何获取**

1. 打开[传承·交大](https://share.dyweb.sjtu.cn/)并选择 jAccount 登录。
2. 由用户完成人工登录或扫码登录。
3. 登录成功后，传承将站点 Token 保存在浏览器本地存储的 `token` 项中。
4. 经用户授权的本地工具从本人已登录的浏览器中读取该 Token，并按工具说明配置到本机。
5. 后续请求通过 `Auth` 请求头携带站点 Token。当前生产接口位于 `api-v2.share.dyweb.sjtu.cn`，不再使用旧 Beta 地址。
6. Token 失效后，重新完成 jAccount 登录并获取新的值。

**数据如何获取**

1. 本轮已通过当前生产接口读取课程详情和资料列表，两个只读请求均正常返回。
2. 资料响应按开课班级组织，并区分尚未归档的资料。
3. 课程搜索、资料详情、积分和个人记录等接口仍需逐项验证。
4. 上传、兑换、下载、评价、评论和举报都会改变账号数据或积分，本轮没有执行。实际操作前应向用户确认。

**可获得的数据范围**

- 已实测：课程详情、开课班级分组和资料列表
- 服务页面可见但未逐项实测：课程搜索、资料详情、积分、上传者信息、评价和评论
- 本人的上传、兑换、下载、积分记录和举报状态：待进一步验证

**可以构建的服务**

- 课程资料检索与收藏导航
- 资料质量和适用范围提示
- 上传前版权、隐私和文件安全检查
- 本人兑换、下载和积分记录整理

## 水源社区

**服务能力**

水源社区基于 Discourse。开发者可以使用 Discourse User API Key，让用户授权读取本人可见的主题、帖子、搜索结果、通知、私信和收藏，并执行授权范围内的社区互动。

**凭证如何获取**

1. 应用在用户设备上生成一对 RSA 公私钥。
2. 应用生成随机 Client ID 和 nonce。nonce 用于核对授权结果。
3. 生成水源 User API Key 授权链接。
4. 授权链接包含应用名称、公钥、Client ID、nonce 和需要的 read 或 write scope。
5. 不设置远程 auth_redirect 时，水源会在授权页面直接显示加密结果。
6. 用户打开链接，通过 jAccount 登录水源并确认授权。
7. 水源创建与本人账号关联的 User API Key，并用应用公钥加密授权结果。
8. 用户把完整密文交回原应用。
9. 应用使用本机私钥解密，核对 nonce，然后保存 User API Key 和 Client ID。
10. 后续请求同时携带 User-Api-Key 和 User-Api-Client-Id。

这一流程采用 Discourse 官方授权机制。授权形态参考了交大龙虾 Skill 集市收录的 openclaw-sjtu，并经过水源账号实测。

**数据如何获取**

1. 读取当前用户信息，验证 User API Key 对应的账号。
2. 读取 latest、new 和 unread 主题列表，并按照 more_topics_url 继续翻页。
3. 读取 categories、site 和 tags，建立分类、子分类和标签索引。
4. 按主题 ID 读取帖子全文、楼层列表、参与者和相关推荐。
5. 使用 search 按课程名、教师名或其他关键词查找主题和帖子摘要。
6. 读取通知、未读数量、私信会话、个人收藏和阅读摘要。
7. 需要写操作时申请 write scope。当前已验证书签创建、书签删除和楼层点赞；重复点赞会被拒绝，取消点赞也会因当前授权范围不足而被拒绝。发帖、回帖、通知已读和私信写入不能仅凭通用 Discourse 文档推定可用。
8. 增量同步可以从最新主题开始，比较 last_posted_at 后停止继续翻页。
9. 长主题可以按楼层 ID 分段读取，避免一次加载全部正文。
10. 每次使用前可读取当前用户接口验证 Key。Key 被撤销、长期未使用后自动失效，或站点策略改变时，接口会拒绝请求，此时重新完成用户授权。Discourse 上游默认在 180 天未使用后撤销 User API Key，但站点可以修改该期限，客户端不应写死有效期。

**可获得的数据范围**

- 最新主题、新主题和未读主题
- 分类、子分类和标签
- 主题标题、发布时间、回复数和最后回复时间
- 帖子全文、楼层和参与者
- 搜索结果及正文摘要
- 通知及已读状态
- 私信会话
- 个人收藏
- 个人资料和阅读统计
- 站点分类结构、通知类型和热门标签
- 获得 write scope 后的书签创建、书签删除和楼层点赞

**可以构建的服务**

- 校园社区信息流
- 分类或标签订阅
- 水源全文搜索
- 课程评价与经验检索
- 校园通知聚合
- 私信和回复提醒
- 个人收藏阅读清单
- 与课表课程关联的课程情报
- 基于帖子内容的个人搜索和问答
