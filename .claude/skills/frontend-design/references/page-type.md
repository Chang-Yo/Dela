# 页面类型判断和风格偏好

需要根据具体产品和业务类型来确定网页类型。

## 后台系统

主要用于数据汇总整理，查看表单。风格比较保持，注重功能性、简洁性和易用性。

风格建议：

- 系统默认字体
- 保守而统一的配色
- 较小的圆角设计
- 布局采用比较标准的 L1+L2+Workspace 设计
- 保守的动画甚至无动画
- 字号大小变化连续

## 产品展示

主要用于某个趣味产品功能的展示和宣传，需要有引人入胜的设计，给访客留下较好的第一印象

风格建议：

- 对比鲜明的字体大小和字重
- Hero区域有醒目的标题
- 配色的饱和度较高，亮色为主
- 布局大气，精心设计的布局
- 大面积的留白和显眼的标题互相衬托
- 灵动的动画
- 不显眼的线条和分割线，渐变或高斯模糊让边界和交界处过渡自然

## 业务咨询

主要用于比较严肃专业的业务展示网页，注重专业的气质

风格建议：

- 采用适合正经场景的字体
- 布局排版需要有序，传递出一种信任感
- 配色不要过于显眼，气质要给人冷静的感觉
- 动画不花哨，给人稳重的感觉
- 线条用于页面板块的区分，每一节都有一个统一的主题
- 较小的圆角甚至无圆角设计
