# 设计系统

## 如何选择

1. 已有前端代码和设计系统规范的项目，直接沿用原来的标准。
2. 已有前端代码但尚未定义系统规范的项目，阅读代码，提取出合适的设计系统，也可以参考下面的案例。
3. 全新的项目，根据页面类型的风格要求，从下面的案例中选择一套或多套学习。

**设计系统的规范放在单独的文件或文件夹中**（如 `tokens.css` 或主题文件），样式代码只引用 token。

## 尺寸阶梯

以 16px 为基准的倍数，用于字号、图标、容器等尺寸：

```
4px (16 x 0.25)
8px (16 x 0.5)
12px (16 x 0.75)
16px (16 x 1)
24px (16 x 1.5)
32px (16 x 2)
48px (16 x 3)
64px (16 x 4)
96px (16 x 6)
128px (16 x 8)
192px (16 x 12)
256px (16 x 16)
384px (16 x 24)
512px (16 x 32)
640px (16 x 40)
768px (16 x 48)
```

**文本字号**只取阶梯中 12px 到 96px 的值，常用 12 / 16 / 24 / 32 / 48 / 64。标题大小建议为正文的 1.3–1.7 倍（见 `responses.md`）。

## 间距规范

使用 8px 网格系统（8pt Grid System），最小步长为 8px，偶尔辅以 4px 半步微调。所有 margin、padding、gap 都从中选取。

## 颜色规范

- **没有指定主题色系时，默认只使用灰度色阶**
- **禁止文字和背景使用同一色相**，比如浅绿色背景用深绿色文本，浅红色背景用红色文本。宁可不加背景，或者采用不同色相的颜色
- 选择配色时采用完整的一套，便于样式统一

可选色系（色值、角色说明见 `assets/palettes/` 下对应的 CSS 文件，可直接复制进项目的主题文件）：

| 色系   | 文件         | 特点                             |
| ------ | ------------ | -------------------------------- |
| 灰色   | `gray.css`   | 浅色，中性灰阶，绿色仅作点缀     |
| 蓝色   | `blue.css`   | 浅色，冷灰底，蓝色为唯一的交互色 |
| 棕色   | `brown.css`  | 暗色，暖调近黑底，橙色作点缀     |
| 蓝紫色 | `violet.css` | 浅色，白底，靛紫为主色           |
| 米黄色 | `beige.css`  | 浅色，暖调米白底，橙色仅作装饰   |
| 彩色   | `vivid.css`  | 暗色，近黑底，酸橙色为主操作色   |

## 圆角风格

根据页面风格选择对应的圆角风格。

### 无圆角

不设置圆角，采用清晰的直角和直线设计。

### Vercel 风格

| Element | Value  |
| ------- | ------ |
| nav     | 2px    |
| cards   | 6px    |
| pills   | 9999px |
| buttons | 6px    |

### Apple 风格

| Element | Value |
| ------- | ----- |
| tags    | 980px |
| cards   | 8px   |
| images  | 8px   |
| inputs  | 8px   |
| buttons | 980px |

### shadcn 风格

| Element | Value |
| ------- | ----- |
| cards   | 24px  |
| small   | 6px   |
| badges  | 18px  |
| inputs  | 18px  |
| nested  | 10px  |
| buttons | 18px  |

### Goodnotes 风格

| Element | Value |
| ------- | ----- |
| tags    | 10px  |
| cards   | 10px  |
| links   | 4px   |
| inputs  | 10px  |
| buttons | 10px  |

## 动画 token

动画的时长和缓动同样预先定义，所有动画从中选取。下面的数值是示例，按页面风格调整（用法见 `motion.md`）：

```
--duration-fast: 150ms;
--duration-base: 250ms;
--duration-slow: 400ms;
--ease-enter: cubic-bezier(0.2, 0, 0, 1);
--ease-exit: cubic-bezier(0.4, 0, 1, 1);
```
